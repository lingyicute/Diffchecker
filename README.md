# Diffchecker

零依赖、纯前端的离线对比工具集。所有处理都在浏览器本地完成，不会上传任何数据。

| 页面 | 功能 |
| --- | --- |
| `text-compare.html` | 文本对比：并排 / 统一视图，智能 / 按词 / 按字符的行内差异，语法高亮，忽略规则，导出 PDF / Excel / PNG / `.diffchecker` |
| `image-compare.html` | 图片对比：并排、淡入淡出、闪烁、滑块、高亮、差值，自动 / 手动对齐，差异区域检测，导出 PNG / PDF |
| `excel-compare.html` | 表格对比：`.xlsx` / `.csv` / `.tsv`，按表头或按行匹配，导出 Excel / CSV / PDF / `.diffchecker` |

## 使用

直接用浏览器打开 `index.html`（会跳转到文本对比），无需构建，也无需联网。
界面语言默认跟随浏览器语言，可在右上角切换中文 / English。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` / `⌘` + `Enter` | 文本页：开始对比 |
| `Esc` | 关闭右侧工具栏与各类弹窗（图片页的“对齐提示”等同于“跳过”） |
| `1` / `2`（按住） | 图片页闪烁模式：临时显示原图 / 修改后的图片 |

## 说明

- 文本与 CSV 文件会优先按 UTF-8 解码，失败时按严格的 GB18030 解码（常见的 GBK 中文文件不会乱码），仍不合法时再回退到 windows-1252（Latin-1 的西欧文本不会被误读成 GBK 乱码）。
- `.diffchecker` 文件保存两侧内容与选项（表格页还会保存所选的表头行），可在对应的页面重新打开；文本页与表格页的文件互不通用。
- 文本页与表格页带有严格的 CSP（`default-src 'none'`），不会加载任何外部资源。图片页的 CSP 仅额外放行同源脚本、`blob:` 与 `wasm-unsafe-eval`，用于可选的 OpenCV 对齐：只有在你自行把 `opencv.js` 内联（或在页面脚本之前以 `<script>` 引入）后才会启用，默认使用内置的 FFT 相位相关对齐。
- 文本页的语法高亮按整篇文本计算，跨行的注释与字符串也能正确着色。
- 表格页读取 `.xlsx` 数值时按 15 位有效数字处理（与 Excel 显示一致），导出的 `.xlsx` 会按表头长度设置列宽。
- 图片页交换两张图片时，会同步反转已有的对齐参数（旋转 / 缩放 / 平移），已对齐的结果不会丢失。
- 不支持旧版二进制 `.xls`，请先另存为 `.xlsx` 或 `.csv`。
- 文本页与表格页的“隐藏未修改的行”会折叠首尾的未修改块（只折叠两行及以上），点击折叠条可展开。
- 表格页读取 `.xlsx` 时，纯时间格式的单元格显示为 `HH:MM:SS`，`veryHidden` 工作表同样标记为“已隐藏”；替换任一侧文件后，已显示的对比结果会自动刷新。
- 表格页导出 CSV 时，以 `=`、`+`、`-`、`@` 开头的非数字文本会加上单引号前缀，避免用 Excel 打开时被当作公式执行；导出 `.xlsx` 时不受影响。
- 导出文件名在原文件名没有主干（如 `.gitignore`）时会回退为完整文件名；导出 `.xlsx` 时会过滤 XML 不允许的字符与孤立代理项，避免 Excel 提示文件损坏。

- 文本页的改动块里删除行与新增行行数不等时，会先按词集合相似度找出互相对应的行（保持两侧顺序、互不交叉），再并排显示；锚点之间仍按序号对应，因此新增 / 删除的行不会把后面的修改行错位配对。
- 导出 `.diffchecker` 时保存的是当前页面的视图类型（并排 / 统一），而不是导出对话框里临时选择的布局。
- 表格页解析 CSV 时，引号只在字段开头才表示“带引号字段”（`5" pipe` 里的引号按字面处理）；自动识别分隔符时会忽略引号内的内容，并兼容只有 `\r` 的换行。
- 表格页仅在文件头是完整的 ZIP 签名时才按 `.xlsx` 解析，因此以 `PK` 开头的 CSV（例如主键列 `PK`）不会被误判；1900 日期系统下 1900-03-01 之前的序列号（Excel 的闰年错误）也会得到正确的日期。
- 表格页的相似行配对只保留 A、B 两侧顺序一致的配对，避免交叉配对让结果里的行序错乱。
- 文本页导出 PNG 时同样遵循“隐藏未修改的行”（折叠条显示为一行）；结果仍然过高（超过 32000px）时会提示改用折叠、PDF 或 Excel，而不是笼统的“导出失败”。
- 文本页打开含 NUL 字节的文件（几乎一定是二进制文件）时会直接提示，而不是把乱码填进文本框；超长行（词元总数超过 20000，如压缩后的 JSON）的行内差异只裁掉公共前后缀、中间整体标记为改动，避免页面卡死。
- 关闭“自动换行”后打印 / 导出 PDF 会强制换行，长行不再被页面边缘截断；表格页打印时同样取消粘性定位与列宽上限，宽表不会被截断。
- 表格页的文件选择器同样放行 `.diffchecker`（以及 `.xltm`）；`[h]:mm:ss` 之类的时长格式按累计 `HH:MM:SS` 显示（可超过 24 小时），不再被当作 1900 年的日期；工作簿 / 工作表 XML 损坏时会明确报错，而不是静默读成空表。
- 表格页的日期规范化会把 `2024/3/5`、`15.03.2024`、`03/15/2024` 之类的文本统一成 ISO 日期再比较；`x/y/yyyy` 在第二位大于 12 时按 月/日/年，其余按 日/月/年。
- 表格页载入 `.diffchecker` 前会先校验两侧表格结构，损坏或类型不符的文件会提示“不是由 Excel 对比工具生成的”，不会只载入一侧；解压 xlsx 时无压缩块的长度与补码不符、数据被截断同样会报错，而不是静默补零。
- 文本页的语法高亮结果按“语法”选项缓存在本次对比结果上，展开折叠块、切换视图 / 粒度时不再重新解析整篇文本；差异表格的制表符宽度为 4 格，与输入框、PNG 导出一致。
- 提示条（“已复制”“加载失败”等）是 `role="status"` 的 aria-live 区域，并适配深色主题。

- 文本页的自定义忽略规则会和正文一样先做引号 / 破折号 / 小写规范化再匹配：开启“忽略引号差异”后规则里的弯引号、开启“转为小写”后规则里的大写字母都能正常生效。

- 表格页的“隐藏未修改的列”会保留整行新增 / 删除的行里有内容的列，新增行的数据不会因为所在列没有单元格级改动而被藏起来。

- 表格页读取 `.xlsx` 的内联字符串（`t="inlineStr"`）时与共享字符串一样跳过 `rPh` 注音文本，日文等带注音的单元格不会读成“正文＋注音”。

- 表格页解析 CSV 时，文件末尾没有换行、且最后一行只有一个空的带引号字段（`""`）时，这一行不会再丢失。

- 表格页的日期规范化还会把 `2024-03-05 00:00:00` 视同纯日期 `2024-03-05`、把 `9:30` 之类的文本时间统一成 `09:30:00`，与 .xlsx 日期 / 时间单元格的显示一致，CSV 与 xlsx 互相对比时不会因此判为不同。

- 表格页单元格的行内差异同样设有上限：词元总数超过 20000 的超长单元格只裁掉公共前后缀、中间整体标记为改动，避免页面卡死。

- 文本页与表格页的折叠条（“N 行未修改，点击展开”）可以用 `Tab` 聚焦、`Enter` / `Space` 展开；文本页的两个输入框带有读屏用的 `aria-label`。

- 表格页“显示公式”模式下，`.xlsx` 里的共享公式（`t="shared"`，只有主单元格存有公式文本）会按位移还原出每个单元格自己的公式：相对引用随行列平移，`$` 锁定的行 / 列、字符串与带引号的工作表名保持不变。

- 文本页与表格页的差异算法（线性空间的 Myers）设有代价上限：重复行极多、差异量极大的文件（如两份各 2 万行的随机日志）会在代价超过上限时改为“尽力而为”的切分，结果仍是合法的差异，只是未必最短，页面不会因此卡死数十秒。

## 测试

项目本身零依赖；回归测试直接从页面的内联脚本中抽取差异核心、表格对比、CSV / 日期解析，以及图片页的膨胀、分组检测、相位相关与对齐参数求逆等纯函数，用 Node 自带的测试运行器执行：

```sh
node --test
# 或
npm test
```

仓库带有 GitHub Actions 工作流（`.github/workflows/test.yml`），每次推送与 PR 都会运行同样的测试。
