# Diffchecker

[English](README.en.md) | 简体中文

零依赖、纯前端的离线对比工具集，支持文本、图片和表格。所有处理都在浏览器本地完成，不会上传任何数据，也不需要联网。

| 页面 | 用途 |
| --- | --- |
| `text-compare.html` | 文本对比 |
| `image-compare.html` | 图片对比 |
| `excel-compare.html` | 表格对比（`.xlsx` / `.csv` / `.tsv`） |

## 快速开始

无需安装和构建：用支持原生对话框的现代浏览器打开 `index.html`（会跳转到文本对比），或把整个目录放到任意静态服务器上即可。

界面语言默认跟随浏览器，可在右上角切换中文 / English，也可切换深色 / 浅色主题。

## 功能

### 文本对比

- 并排 / 统一两种视图；行内差异支持智能、按词、按字符三种粒度。
- 语法高亮（JSON、JavaScript / TypeScript、Python、XML / HTML、CSS、SQL，可自动识别），跨行的注释和字符串也能正确着色。
- 预处理与忽略规则：忽略空白差异、转为小写、按行排序、去除行首行尾空白、换行替换为空格、忽略引号 / 破折号差异，以及自定义忽略词。
- “隐藏未修改的行”会折叠长段相同内容，点击折叠条（或用 `Tab` 聚焦后按 `Enter` / `Space`）即可展开。
- 行数不等的改动块会先按相似度找出对应的行再并排显示，新增 / 删除的行不会让后面的修改行错位。
- 可打开文件或直接把文件拖进输入框；也可开启“实时比较”。
- 导出 PDF、Excel、PNG 或 `.diffchecker` 文件。

### 图片对比

- 六种模式：并排、淡入淡出、闪烁、滑块、高亮、差值。闪烁可暂停，系统开启“减少动态效果”时默认暂停；滑块支持方向键和 Home / End。
- 触屏上可直接在对比画面上纵向滑动页面。点击画面内的“平移和缩放”可拖动画面或双指缩放，再点一次恢复页面滚动。
- 自动 / 手动对齐（平移、旋转、缩放、翻转），尺寸不同的图片会提示是否自动对齐。对比画布包含两张图变换后的范围，不裁掉移到原画布外的内容。
- 自动检测差异区域并列出，可点击定位；检测灵敏度可调，支持多组检测叠加。
- 支持粘贴剪贴板里的图片（`Ctrl` / `⌘` + `V`）；有焦点的图片输入区优先接收。
- 比较包含图片透明度；导出原始分辨率或工作分辨率的 PNG，或导出带摘要、未对齐的源图片和差异列表的 PDF 报告。

### 表格对比

- 读取 `.xlsx`（含 `.xlsm`、`.xltx`、`.xltm`）、`.csv`、`.tsv`，可选择工作表和表头行（会自动跳过表头上方的标题行）。
- “按表头”匹配行列（能识别新增、删除和移动的列），或“按行”逐行比较；可显示单元格的值或公式。
- 选项：忽略空白、忽略大小写、统一日期格式、对行 / 列排序后再比较、隐藏未修改的行 / 列、在修改的单元格中显示旧值。
- 导出 Excel、CSV、PDF 或 `.diffchecker` 文件。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` / `⌘` + `Enter` | 文本页：开始对比 |
| `Esc` | 关闭右侧工具栏和各类弹窗 |
| `1` / `2`（按住） | 图片页闪烁模式：临时显示原图 / 修改后的图片 |

## 文件与格式说明

- **编码**：文本和 CSV 文件优先按 UTF-8 解码，失败时依次尝试 GB18030（常见的 GBK 中文文件不会乱码）和 windows-1252（西欧文本）；UTF-16 无论是否带 BOM 也能识别（没有 BOM 时按 NUL 字节的分布判断）。
- **二进制文件**：文本页打开含 NUL 字节的文件时会直接提示，而不是把乱码填进输入框。
- **`.diffchecker` 文件**：保存两侧内容和当前选项，可在对应页面重新打开；不支持的会话版本不会载入。文本页与表格页的文件互不通用。
- **不支持的格式**：旧版二进制 `.xls` 请先另存为 `.xlsx` 或 `.csv`；加密 / 设有密码的工作簿请先取消密码。
- **日期与数值**：表格页读取 `.xlsx` 数值时按 15 位有效数字处理（与 Excel 显示一致）。开启“统一日期格式”后，`2024/3/5`、`15.03.2024`、`2024-03-05 00:00:00` 等文本会按 ISO 日期比较，`9:30` 会按 `09:30:00` 比较，因此 CSV 与 `.xlsx` 互相对比时不会因格式不同而误报。形如 `x/y/yyyy` 的日期在第二位大于 12 时按“月/日/年”，其余按“日/月/年”。XLSX 的 ISO 日期和指定了小数秒的时间格式保留至多三位小数秒；不把带时区的非标准日期截成无时区时间。
- **导出 CSV**：非数字文本开头的 `=`、`+`、`-`、`@`（含全角形式、前面有空白的情况）会触发单引号前缀，避免被当作公式；带符号的纯数字不受影响。导入时会识别多行引用字段；引用未闭合或闭合引号后多出内容会报错。多种分隔符难以区分时，可先另存为 `.tsv` 或 `.xlsx`。
- **大文件**：差异算法对重复行极多、差异量极大的文件设有代价上限，此时结果仍是合法的差异，但不一定最短；超长的行或单元格只会裁掉公共前后缀，中间整体标为改动。
- **文本 PNG**：长行自动换行。宽度为 1600 px，画布最多 16 Mi 像素。超出上限时，请开启“隐藏未修改的行”，或改为导出 PDF / Excel。
- **图片限制**：单张最多 32 Mi 像素，最长边 16384 px；浏览器的画布上限更小时（如 iOS Safari）会自动缩小后载入。预览和差异区域检测最长边为 2600 px，PNG 最多 16 Mi 像素，过大时可选择工作分辨率。
- **表格限制**：单个 XLSX 部件解压后最多 64 MiB；每个工作表最多导入 100 万个单元格 / 字段，合并展开两侧的比较预算为 50 万个位置（含行号列）。不比较工作簿中的图表页。XLSX 导出超出 Excel 行、列或单元格长度限制时会提示改用其他格式。

## 隐私与安全

- 页面带有严格的内容安全策略（CSP）：文本页和表格页为 `default-src 'none'`，不会加载任何外部资源；图片页仅额外放行同源脚本、`blob:` 和 `wasm-unsafe-eval`。
- 图片对齐默认使用内置的 FFT 相位相关算法。如果你自行把 `opencv.js` 内联进页面（或在页面脚本之前以 `<script>` 引入），会在同时允许旋转和缩放且无翻转时尝试 OpenCV 的 ORB 特征点对齐；其余情况使用内置算法。

## 开发与测试

项目本身零依赖。回归测试直接从页面的内联脚本里抽取差异核心、表格对比、CSV / 日期解析、zip 读写，以及图片页的区域检测和对齐算法，用 Node 自带的测试运行器执行（需要 Node 18 或更高版本）：

```sh
npm test
```

每次推送和 PR 都会通过 GitHub Actions 运行同样的测试。

可选的浏览器冒烟测试覆盖 Chromium 和 WebKit 的移动尺寸、手势及离线导入导出；测试依赖不进项目。可在仓库外安装 Playwright，运行 `playwright install chromium webkit` 下载浏览器，然后以 `PLAYWRIGHT_PACKAGE` 指向该包的绝对路径，运行 `node scripts/browser-smoke.cjs`。
